# PoE2 Craft Calculator

Calculadora de custo de craft para Path of Exile 2 — liga Forbidden Rites.

## Funcionalidades
- Preços automáticos via poe.ninja
- Nome e descrição de receitas
- Notas por passo do craft
- Salva receitas no navegador
- Exporta/importa JSON
